# Treehouse Newsletter Signup

A small Vue application for viewing, adding, and removing newsletter subscribers.

## Setup

Install the dependencies:

```sh
npm install
```

Create a `.env` file in the project root and add the API key:

```sh
VITE_API_KEY=your_key_here
```

Then start the development server:

```sh
npm run dev
```

## Other commands

```sh
npm run build
npm run preview
```
